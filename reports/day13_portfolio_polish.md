## Portfolio review checklist

Before publishing the project externally, confirm that:

1. The notebooks execute successfully with internet access to the UCI source.
2. Numerical findings shown in screenshots or portfolio copy come from an executed notebook run.
3. Any Power BI screenshots come from a real `.pbix` built in Power BI Desktop.
4. Repository links and notebook names match the final GitHub structure.
5. No temporary files, local environments, credentials, or large raw-data copies are committed.
6. The final README describes what was actually built rather than implying unsupported artifacts.
